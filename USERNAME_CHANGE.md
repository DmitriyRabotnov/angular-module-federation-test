# GitHub Username Change

This document explains the GitHub username change from `DmitriyRabotnov` to `DmitriiRabotnov`.

## What Changed

The GitHub username was updated from `DmitriyRabotnov` to `DmitriiRabotnov` in GitHub account settings.

## Impact

- **Repository URL**: The repository URL has changed from:
  - Old: `https://github.com/DmitriyRabotnov/angular-module-federation-test`
  - New: `https://github.com/DmitriiRabotnov/angular-module-federation-test`

- **Automatic Redirects**: GitHub automatically redirects the old URL to the new one, so existing clones will continue to work.

## For Contributors

If you have a local clone of this repository, you can update the remote URL with:

```bash
git remote set-url origin https://github.com/DmitriiRabotnov/angular-module-federation-test
```

To verify the change:

```bash
git remote -v
```
